# In the Trenches

An 18-year-old volunteer's war, 1915 to the Armistice. Choose your exposure, not the war.

Status: Phase 1 (engine and instruments). Read in order: `docs/SPEC.md` (approved),
`docs/KILLGATE.md` (the numbers model, passed), `docs/DESIGN.md` (approved). Built with the
HeirsOfRuin game-building skills (`Game-Workshop/skills/`): game-scaffold shape C and
game-narrative's story engine.

## Run

```
npm install
npm run dev          # Vite dev server
npm run check        # build, tests, validate, text tools, bot, bundle, phone smoke test
npm run proto:gate   # the kill-gate prototype's tables (retired at the end of Phase 1)
```

## Play as an app

Once the Pages workflow has run on the default branch: open
https://heirsofruin.github.io/WW1/ on a phone and choose Install (Chrome) or Share, Add to
Home Screen (Safari). It plays with the network off. Menu, Copy a save code moves a game.
