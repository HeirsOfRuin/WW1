# Kill-gate prototype: retired

The Stage 2 numbers model (docs/KILLGATE.md). Phase 1 ported it into the game as the war layer
and the game reproduced it exactly. Retired on 2026-11-09, when duties and role missions became
three-step sorties at the author's request (docs/FRAME-PLAYTEST1.md): the game no longer plays
this model's war, by design. Kept as the record of how the targets were first met; not run, not
maintained. Measure the game with `npm run gate`.
